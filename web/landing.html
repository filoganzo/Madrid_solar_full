Madrid rooftop solar, from first principles

A working model of what rooftop photovoltaics is worth in Madrid, built from the sun's position upward rather than from a kWh/kWp lookup downward. Written as a case study, not a proposal.

What the model does

The obvious question is how much rooftop solar Madrid could hold. In Spain that has an uninteresting answer, because the sun is not the constraint. The question worth the work is different: if you already supply electricity in Britain and you are moving into Spain, does the same rooftop product work, and if not, what breaks first?

So the physics is implemented rather than looked up — NOAA solar position, Ineichen–Perez clear sky, Erbs diffuse split, Hay–Davies transposition, Faiman cell temperature, and a geometric horizon computed per panel from real building footprints. The unit of analysis is one panel, because the decision is marginal: the last row added to a roof is often the one that loses money.

What it found

  • Sunshine is not the Spanish constraint — roof per household is. About 0.97 kWp per dwelling where a British semi has roughly 4 kWp. Six floors share one roof.
  • A Spanish kilowatt-hour avoided is worth about half a British one. €0.133/kWh demand-weighted against 26.11 p. More sun, a fifth of the revenue.
  • The product is not a panel. It is a signed resolution from a comunidad de propietarios. One flat alone pays €4.16/Wp and never pays back; the whole building together pays €0.64/Wp and returns in 4.3 years. Same hardware, same sun. The difference is who signed.
  • Urban shading costs 2.3%, not the 20% that dense-city intuition suggests — and that finding demolished my own top data request, which is the most useful thing the model did.
  • A domestic battery is a poor household investment and a good trading asset, which is an argument for vertical integration made in arithmetic rather than in slogans.
The write-up includes a section called “Where I was wrong”, listing five bugs that changed the answer and one claim I had to withdraw, each now covered by a regression test. They are in the repository because the corrections are the most informative part of the build.

Running it

Everything is reproducible from the repository: python run_madrid.py for the block study, python run_city.py for the city. Every input lives in one config file with a source and a confidence label, and the test suite checks the physics against arithmetic that cannot be wrong — equinox noon altitude must equal 90 − latitude.
